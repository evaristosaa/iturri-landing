# ITURRI Landing Page

Landing page moderna y profesional para **ITURRI** - "People who care for people"

## 🎯 Descripción

Página web corporativa diseñada para Iturri, empresa líder en soluciones de seguridad y protección desde 1947. La landing page refleja los valores de innovación, eficiencia y sostenibilidad de la compañía.

## ✨ Características

- **Diseño moderno y limpio** con tipografía Inter
- **Responsive mobile-first** - perfecta visualización en cualquier dispositivo
- **Animaciones suaves** con CSS y JavaScript vanilla
- **Optimizada para rendimiento** - sin frameworks pesados
- **Formulario de contacto** con validación
- **Scroll suave** entre secciones
- **Efectos de parallax** en el hero
- **Contador animado** de estadísticas

## 🎨 Colores Corporativos

- **Azul oscuro**: `#003366` (color principal)
- **Naranja**: `#FF6B35` (color de acento)
- **Gris claro**: `#F5F5F5` (backgrounds)

## 📋 Secciones

1. **Hero** - Claim principal "People who care for people"
2. **Sobre Nosotros** - Historia desde 1947
3. **Soluciones** - 4 áreas principales:
   - Vehículos de emergencia
   - Ambulancias
   - Ropa de trabajo
   - EPIs y Exoesqueletos
4. **Por qué elegirnos** - Innovación, Experiencia, Sostenibilidad, Servicio integral
5. **Contacto** - Formulario funcional y datos de contacto

## 🛠️ Tecnologías

- **HTML5** - Semántico y accesible
- **CSS3** - Variables CSS, Grid, Flexbox

## 🚀 Instalación

```bash
# Clonar el repositorio
git clone <repository-url>

# Navegar al directorio
cd iturri-landing

# Abrir en el navegador
open index.html
# o
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`

## 🔧 Personalización

### Cambiar Colores

Edita las variables CSS en `styles.css`:

```css
:root {
    --primary-color: #003366;    /* Azul principal */
    --accent-color: #FF6B35;     /* Naranja acento */
    --light-bg: #F5F5F5;         /* Fondo claro */
}
```

### Añadir Imágenes

Reemplaza los placeholders en el HTML:

```html
<!-- Ejemplo -->
<img src="images/emergency-vehicle.jpg" alt="Vehículo de emergencia">
```

### Modificar Contenido

Todo el contenido está en `index.html` con clases semánticas para fácil identificación.
